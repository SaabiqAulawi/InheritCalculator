# Kalkulator Warisan

Aplikasi kalkulator pembagian warisan Islam dengan antarmuka responsif.

## Menjalankan lokal

```bash
npm start
```

Buka alamat yang ditampilkan oleh server, biasanya `http://localhost:3000`.

## Deploy ke Vercel

1. Push folder ini ke repository GitHub/GitLab/Bitbucket.
2. Import repository di Vercel.
3. Framework preset: **Other**.
4. Build command: dikosongkan.
5. Output directory: `.` atau root proyek.

Aplikasi ini tidak memerlukan variabel lingkungan atau proses backend.
